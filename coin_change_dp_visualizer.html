How Coin Change DP Works

This visualization steps through the exact bottom-up dynamic programming code you provided:

  • dp[0] = 0: Zero coins are needed to make amount 0. All other amounts start at `MOD` (infinity).
  • Outer loop (i): We iterate through every amount from 1 up to the target amount `m`.
  • Inner loop (j): For each amount `i`, we test every coin denomination `a[j]`.
  • Transition: If the coin fits (`i - a[j] >= 0`), we check if `dp[i - a[j]] + 1` is smaller than the current `dp[i]`.
