# CSES-1634-coin-changes-DP
just to understand procces made little bit site 
Interactive Coin Change DP VisualizerA web-based tool designed to help programmers and students understand how the Minimum Coin Change Problem is solved using Bottom-Up Dynamic Programming (DP).Key FeaturesInteractive Playback: Control the execution flow with Step Forward, Step Backward, and Auto Play buttons to see how the dp array fills up index by index.Custom Parameters: Test different coin combinations, target amounts, and infinity values on the fly.Real-Time Code and State Tracking:Highlights the active target amount and the specific coin being evaluated.Tracks lookback states and updates minimum values dynamically.Live console logs explaining every transition.Algorithm ComplexityTime Complexity: O(n \times m) — iterates through m target amounts for each of the $n$ coin types.Space Complexity: O(m) — utilizes a 1D vector of size m + 1 to store minimum coin counts.
